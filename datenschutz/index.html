Norn Shorts und die YouTube API

Norn Shorts ist ein privates Werkzeug, mit dem [Vor- und Nachname] auf dem eigenen Rechner kurze Videos produziert und auf die eigenen YouTube-Kanäle hochlädt. Es wird niemandem sonst angeboten.

Worauf es zugreift

Mit Zustimmung des Kanalinhabers über Google OAuth nutzt das Werkzeug die YouTube Data API, um Videos auf den Kanal des Inhabers hochzuladen und ihren Sichtbarkeitsstatus zu ändern, und die YouTube Analytics API, um Aufrufe und Zuschauerzahlen dieser Videos zu lesen. Auf andere Google-Daten greift es nicht zu.

Wo die Daten liegen

Alles bleibt auf dem Rechner des Inhabers. Das OAuth-Refresh-Token liegt in einer lokalen Datei, die nur das Konto des Inhabers lesen kann. Analysezahlen liegen in einer lokalen Datenbank. Nichts wird verkauft, geteilt oder an Dritte übermittelt.

Wie lange

Tokens bleiben gespeichert, bis der Inhaber den Zugriff widerruft. Analysezahlen bleiben so lange, wie der Inhaber die lokale Datenbank behält.

Zugriff widerrufen

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Das Löschen der lokalen Token-Datei hat für das Werkzeug dieselbe Wirkung.

Google und YouTube

Das Werkzeug nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Norn Shorts privacy policy, English

Norn Shorts is a private tool that [operator name] runs on their own computer to produce and upload short videos to their own YouTube channels. It is not offered to anyone else.

What it accesses

With the channel owner's consent through Google OAuth, the tool uses the YouTube Data API to upload videos to the owner's channel and to change their privacy status, and the YouTube Analytics API to read view and audience figures of those videos. It requests no access to any other Google data.

Where data is kept

Everything stays on the owner's computer. The OAuth refresh token is stored in a local file readable only by the owner's account. Analytics figures are stored in a local database. Nothing is sold, shared or sent to third parties.

How long

Tokens are kept until the owner revokes access. Analytics figures are kept as long as the owner keeps the local database.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file has the same effect for the tool.

Google and YouTube

The tool uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and Google's privacy policy applies.
