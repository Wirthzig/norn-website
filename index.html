Norn Shorts and YouTube API Services

Norn Shorts is a private production tool that Alexander Wirths runs on his own computer to produce short videos and upload them to his own YouTube channels. It is not offered to anyone else and no one else can sign in to it. Norn Shorts uses YouTube API Services.

What it accesses

With the channel owner's consent given through Google OAuth, the tool uses the YouTube Data API to upload videos to the owner's channel and to change their privacy status, and the YouTube Analytics API to read view and audience figures of those videos. It requests no access to any other Google data.

How the data is used, stored and shared

The data is used only to publish the owner's videos and to show the owner how they perform. Everything stays on the owner's computer. The OAuth refresh token is kept in a local file that only the owner's account can read, and analytics figures are kept in a local database. Nothing is sold, shared with third parties or used for advertising. The tool sets no cookies and collects no data from any device other than the owner's.

Norn Shorts' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How long

Tokens are kept until the owner revokes access. Analytics figures are kept as long as the owner keeps the local database.

Revoking access

Access can be revoked at any time on the Google security settings page, security.google.com/settings/security/permissions. Deleting the local token file has the same effect for the tool.
